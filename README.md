# HOLLOW KEEP

A first-person medieval dungeon horror-action game: four levels, a three-phase boss,
PBR textures and 20 real CC0 props from Poly Haven, rendered with a pixel-art PBR pipeline.

**Play:** https://mtlsplat.github.io/hollowkeep/

Controls: WASD move, mouse look, LMB attack, RMB block, E interact, Tab inventory, Esc pause, F11 fullscreen.

Built with Three.js + Vite. Textures & props: Poly Haven (CC0). See CREDITS-ASSETS.md in the source repo.
